You will learn how to load .glb assets, manipulate node transforms (position, rotation, scale), attach and detach modular parts (like spoilers and vents), and structure your state management for smooth runtime updates.Core Concepts & API Reference1. Loading Assets (Node.fromGlbAsset)flutter_scene parses standard Binary GLTF (.glb) files into a tree of Node objects. Each node can hold meshes, materials, and children transformations.Syntax: await fscene.Node.fromGlbAsset('path/to/asset.glb')Behavior: Loads geometry, lighting metadata, and default hierarchical structures into memory asynchronously.2. Node TransformationsUnlike general transform matrices in legacy engines, flutter_scene exposes distinct property setters directly on the Node instance:node.position (Vector3): Controls local spatial coordinates $(x, y, z)$.node.rotation (Quaternion): Controls orientation using quaternion rotations.node.scale (Vector3): Controls scaling factors across each axis.3. Scene Hierarchy & SocketsTo attach aftermarket mods cleanly, your base car model should ideally include socket nodes (empty child nodes positioned at attachment points like the trunk or hood).node.findByName(String name): Searches the node tree recursively for a matching identifier.parentNode.add(childNode): Appends a child node, inheriting parent transformations automatically.childNode.parent?.removeChild(childNode): Detaches a mod node cleanly from the hierarchy.Code SnippetsSnippet A: Initializing and Rendering the SceneDartimport 'package:flutter/material.dart';

class CarSceneViewer extends StatefulWidget {
  const CarSceneViewer({super.key});

  @override
  State<CarSceneViewer> createState() => _CarSceneViewerState();
}

class _CarSceneViewerState extends State<CarSceneViewer> {
  late fscene.Scene _scene;
  late fscene.Node _carModel;
  bool _isInitialized = false;

  @override
  void initState() {
    super.initState();
    _loadSceneAssets();
  }

  Future<void> _loadSceneAssets() async {
    _scene = fscene.Scene();
    
    // Load base car model from assets
    _carModel = await fscene.Node.fromGlbAsset('assets/models/car_base.glb');
    _scene.add(_carModel);

    setState(() {
      _isInitialized = true;
    });
  }

  @override
  Widget build(BuildContext context) {
    if (!_isInitialized) {
      return const Center(child: CircularProgressIndicator());
    }

    return fscene.SceneView(
      _scene,
      cameraBuilder: (elapsedTime) => fscene.PerspectiveCamera(
        position: vm.Vector3(3.0, 1.5, 4.0),
        target: vm.Vector3(0.0, 0.4, 0.0),
      ),
    );
  }
}

Future<void> attachSpoilerMod(String spoilerAssetPath) async {
  // 1. Remove existing spoiler if present
  if (_activeSpoiler != null) {
    _activeSpoiler!.parent?.removeChild(_activeSpoiler!);
    _activeSpoiler = null;
  }

  // 2. Load the new spoiler GLB
  final newSpoiler = await fscene.Node.fromGlbAsset(spoilerAssetPath);

  // 3. Configure precise transforms
  newSpoiler.position = vm.Vector3(0.0, 0.85, -1.5);
  newSpoiler.scale = vm.Vector3.all(1.0);
  
  // Optional rotation tilt
  newSpoiler.rotation = vm.Quaternion.axisAngle(vm.Vector3(1.0, 0.0, 0.0), 0.05);

  // 4. Attach to trunk socket if available, otherwise fallback to root car model
  final trunkSocket = _carModel.findByName('socket_trunk');
  if (trunkSocket != null) {
    trunkSocket.add(newSpoiler);
  } else {
    _carModel.add(newSpoiler);
  }

  _activeSpoiler = newSpoiler;
}
